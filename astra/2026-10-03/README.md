# First Astra × Haven build

October 3, 2026

This is the Astra-generated personal Haven surface from our first Haven collaboration with Astra, preserved as project history.

## Governing idea

**one mind → one flow → one screen**

ChatGPT is where thinking happens; Haven is the glanceable surface showing what matters right now. Open it, orient yourself, act, and return to life.

The visual language is **Cole Calfee / 1994 personal workstation**: a centered warm-gray field, monospace type, hard rules, square checkboxes, and restrained blocks. No folders, tabs, feeds, or dashboard suite.

## The build

- `haven.html` is the exact finished HTML build, with CSS and JavaScript embedded. No separate assets, dependencies, or build step are required.
- Open `haven.html` in a browser. The screen contains Now Playing, Current Priorities, Outreach Checklist, Active Threads, Direction, and SYSTEM READY_.
- Checkboxes work for the open page and reset on reload. The next-action marker advances through unfinished priorities.
- Content is an authored first brief, not automatically synchronized with ChatGPT. The music link opens Spotify; it does not report live playback.
- The build was checked at 1440×1000, 1280×720, 390×844, and 375×667, with no scrolling at those viewport sizes.

## Separate deployment

The private [ChatGPT Site deployment](https://haven-personal-1994.colecalfee.chatgpt.site) is separate from GitHub. This archive records its finished source; committing it here does not replace, delete, redeploy, or automatically synchronize the Site.

The earlier root-level `haven-personal-1994.html` is retained. This dated directory is the documented first Astra × Haven build.
