# Tangerine website launch

November 17, 2026 · Tangerine. We build brands.

Production: https://ex-tangerina.com/

## Configuration

Squarespace manages DNS. The owner set the apex A record to `76.76.21.21` and the `www` CNAME to `cname.vercel-dns.com`, each with a four-hour TTL. Vercel reported both names correctly configured. The previous Squarespace website records served its holding page. Email security and Domain Connect records were visible separately in the registrar after the change.

The Vercel project is `ex-tangerina`. Its existing permanent redirect sends `www.ex-tangerina.com` to the root domain. The public deployment alias is https://ex-tangerina.vercel.app/. Source lives in `website/index.html` in this repository.

## HTTPS and verification

After the DNS switch, both public names initially failed to serve the homepage. A Vercel certificate was issued for both names with automatic renewal enabled. Subsequent public checks on November 17 at approximately 8:13 p.m. Eastern returned:

- Apex HTTPS GET: HTTP 200, Tangerine homepage.
- www HTTPS GET: HTTP 308, Location https://ex-tangerina.com/. Chrome followed this redirect and displayed “We build brands.”
- Homepage bytes matched the deployment alias and the repository source. Git blob: `945d851152152e00b5550ab33f72eeb0a65b4199`.
- Desktop Chrome on the custom domain: Work, Experiments, About and Back to top reached their anchors by keyboard. The orange button toggled open and closed on click.
- An iPhone Safari user-agent request followed the redirect and received the same HTML. The mobile stylesheet hides the Experiments navigation link at 680px and below. Hands-on phone layout and touch verification are still pending.

No website source edits were required for this launch.
