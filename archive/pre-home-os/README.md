# Haven — Pre-Home OS Archive

Snapshot of the public Haven site immediately before the September 27, 2026 Home OS overhaul.

This material is preserved as design history, not current product direction. It includes the founding cyberspace/cathedral draft, the monastery-vault variant, the Security / Keep / Families exploration, and the prior visual system.

The original phrase **“In cyberspace as it is in heaven”** remains part of Haven's lineage. The current product translates that ambition into something concrete: technology put back in its proper place, beginning with the home.
