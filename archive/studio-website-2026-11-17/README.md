# Tangerine studio website — archived 18 November 2026

`index.html` is the studio website ("We build brands.") that served https://ex-tangerina.com/ from its launch on 17 November 2026 until the smartscreen became the homepage on 18 November 2026.

It is preserved unchanged here, byte for byte (git blob `945d851152152e00b5550ab33f72eeb0a65b4199`, the blob recorded in `docs/launch/2026-11-17.md`). Its full history is reachable with `git log --follow archive/studio-website-2026-11-17/index.html`.

It is an archive, not a deployed page: the Vercel project serves only `website/`. To view it, open the file locally in a browser.

Its Orange Study No. 001 drawing continues on the homepage as a static image, `website/media/orange-study-001.svg`, extracted unchanged from this file's markup in its closed state.
