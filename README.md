# Tangerine

**A life, in evidence.**

Tangerine is a private, source-grounded archive for a creative life: keep original work, return to unfinished threads, and look back at what actually happened. AI may help index and connect the record but must never silently edit the originals.

## Legacy Haven — archived

All pre-consolidation Haven source and its history were preserved intact on the [2026-10-25 archive branch](https://github.com/colemanvii/tangerine/tree/archive/haven-before-tangerine-2026-10-25). See [archive/README.md](archive/README.md) for the map of historic concepts and branch names.

**Temporary coexistence:** `main` still contains old Haven runtime files (including root `index.html` and `personal/index.html`) because an existing Vercel project references that work. They are **legacy, not Tangerine's new canonical UI**. Do not delete or overwrite them until the new app's code, secure destination and migration are verified. A GitHub commit does not imply the private production site changed.

## Consolidation rules

1. Work in the private `study/tangerine-wrapped-astra-001` branch until the new importer/report is functioning and reviewed.
2. Preserve authorship, original text, provenance, source links and uncertainty. Never invent usage analytics or claim timestamps equal screen time.
3. Do not commit personal ChatGPT exports, private records, credentials or real usage reports.
4. Do not make private experiments public by deploying them or changing repository visibility.
5. Promote the reviewed app into a deliberately selected canonical source and **only then** retire the legacy runtime, while keeping the historical archive available.

**Status (2026-10-25):** Tangerine is the product name and repository. The older Haven work is snapshotted; the new Wrapped study is in progress. No new Tangerine production site has been verified.
