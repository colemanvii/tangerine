# Tangerine Studio — Design V1

**Status:** Design study, November 13, 2026. Not approved for production.

This is the first standalone, responsive HTML concept for Tangerine as an independent creative studio led by Cole Calfee.

## Open the study

Open [index.html](index.html) in a browser. The study is self-contained: its layouts, responsive styles, interactions, and original SVG illustrations live in one HTML file. Web fonts load from Google Fonts.

## Direction

- An editorial, warm-white canvas with a distinct tangerine-orange signature
- Oversized serif typography, generous space, and minimal navigation
- Creative partnership stories for Freeman and Joseph Martin, depicted using illustrative artwork rather than approved client photography
- A journal for original writing and experiments
- Guiding tenet: *In cyberspace as it is in heaven.*

## Next iteration

Art-direct real project imagery, refine copy and typography, and connect published journal entries. Do not replace the live site without explicit approval.
