The instrument

Each print is computed from scratch. The seed places fruit, leaves and stems. Lighting and ripeness set how much of each ink a pixel wants. A screen then turns that wish into dots, one bit per ink. The inks overprint like real transparent ink, and each plate can slip out of register.

The four studies

Ripening, peeling, blossoming and decomposition each run 72 frames at 12 frames a second. The dot pattern stays fixed between frames, so the image changes without shimmering, and any frame can be saved as a finished print.

Output

Save the print as a PNG at up to 8×, or a ZIP of separations: one-bit film for each ink, vector SVG plates, a proof sheet and the recipe. The plates are ready for risograph or screen printing. A recipe string reproduces any print exactly.
