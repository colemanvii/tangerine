# Haven Morning

A deliberately small morning orientation surface.

## Product law

**Haven knows a lot. It shows very little.**

The intelligence may be deep underneath, but the morning surface should feel almost too simple to contain what it knows.

## Visual direction

Think:

- early Macintosh
- architecture monograph
- private instrument
- morning newspaper

Do **not** turn this into a terminal aesthetic, a productivity dashboard, or a SaaS interface.

## Frozen rules

- one surface
- no cards
- no pills or badges
- no decorative icons
- no gradients, glow, blur, or shadows
- no ornamental terminal syntax
- no decorative animation
- no metrics on the annual compass
- little metadata
- sharp alignment and hairline rules
- warm paper background
- one restrained monospace family for the prototype
- annual compass is spatial orientation, not progress tracking
- machinery stays underneath; only relevant context surfaces

## Files

- `index.html` — semantic shell
- `styles.css` — visual system
- `content.js` — representative morning content only
- `app.js` — rendering and annual compass
- `GEMINI_BRIEF.md` — implementation brief for the next build pass

## Run

Open `index.html` directly in a browser or serve the repository locally.

No build system or dependency installation is required.

## Privacy note

The current GitHub repository is public. Keep this prototype generic. Do not commit real personal memory, private conversations, health information, relationship details, financial details, private contact data, or other sensitive user context here.

A production Haven should use a private repository and private data layer.
