# Fonts

`instrument-serif-regular.woff2` and `instrument-serif-italic.woff2` are Latin subsets of Instrument Serif, by The Instrument Serif Project Authors. They are licensed under the SIL Open Font License 1.1, and the full licence is in `OFL.txt`. The source was `ofl/instrumentserif/` in github.com/google/fonts, subset with fontTools `pyftsubset` to Basic Latin, Latin-1 and common punctuation.
